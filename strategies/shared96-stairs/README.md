# Shared96 staircase teacher: frozen strategy specification
This code-only design uses a complete warm actor, learned log standard deviation and independent privileged critic. Actor inputs are native raw446 and measured current p45; a trainable 51-feature producer concatenates with p45 into a shared 96→512→256→128→12 mean. No actor observation normalizer is used in this ABI. The critic retains separate native split normalizer state. The whole actor and critic are trainable after admission; “frozen” refers to strategy, source/config and input checkpoint identity, not frozen parameter groups. A new optimizer is explicit: no unknown optimizer lineage is imported into a new stair-task distribution. The unchanged old raw446 teacher is a reference/donor, never a source of weights, replay, curriculum ballots or simulator state.
The native factory is an external repository integration dependency, not bundled here. It must preserve ordered true contacts (six up, landing, six down, front and rear groups), genuine entrance/exit and physical reset/termination/strict settling. The new promotion ledger counts valid whole physical passages from 4 cm, only 0° in both directions; ±15° auxiliary, lower-level review; no inherited votes. Flat retention and fixed peripheral-case evaluation are independent gates. This scaffold neither launches nor declares native readiness or performance. A sanitized digest list binds the exact public source; the private gate controls endpoint admission separately.
