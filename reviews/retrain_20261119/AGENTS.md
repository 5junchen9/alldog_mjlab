# 工作约定

默认中文，优先直观、可读的实现。

- 本仓库是Black和Wolf从零训练的唯一源码入口。历史权重不再作为初始化来源。
- Black、Wolf各自共享教师和学生的actor。两种机器人动作数量和物理含义不同，不共用同一组actor权重。
- 使用`uv run --no-sync --offline python`执行Python。运行前确认`mjlab.__file__`指向本仓库的`src`。
- CPU测试使用`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`，避免系统ROS测试插件混入。
- 先做CPU检查，再做有限步数GPU检查。长训练、晋级资格和实机能力必须分别记录。
- 修改动作、观测、相机或奖励后更新对应文档及测试。不能把旧架构的验证结果算到新架构上。
- Git保存源码、必要模型资产、说明和紧凑验证结果。权重、逐步轨迹、缓存和运行日志放`runs/`，不提交重复压缩包。
- Wolf资产含团队模型，只保存在本地或明确授权的私有仓库；上传前检查仓库可见性和资产授权。
- 清理旧目录前先验证本仓库不依赖它，并记录删除清单。不要修改共享环境中的硬链接原文件。
