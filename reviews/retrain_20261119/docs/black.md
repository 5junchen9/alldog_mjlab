# Black从零训练

新入口为`black.run`。全部参数随机初始化，包括HIM、共享动作头、地形编码器和学生视觉模块。新模型使用`black_retrain_shared_actor_v3`身份，旧工程存档不会被默认或隐式读取。必要经验、源文件和来源身份已提取到当前项目，旧工程按清理清单删除。

## 课程顺序

1. `flat_foundation`：全平地，静止起步、基础轴运动、停车。
2. `flat_axes`：全平地，低速纯轴起动、反转、停车。
3. `general`：25%平地，75%坡上/坡下、楼梯上/楼梯下、粗糙地面和波浪地面。平地保留原低速、全向和高速命令分布。
4. `specialty`：从合格综合教师分别分支到`stairs`、`platform`、`high_wall`、`slope`、`broken_bridge`、`plum_stakes`。专项由独立`--task`选择，每项保留25%平地。

综合六域与六个专项是两组不同任务。专项分支继承新综合教师；“全部从头”指整条新训练线从随机参数开始，专项不必重新丢弃已学会的行走能力。各阶段需要当前教师、当前源码对应的原始评估记录。评估程序重新评分，手填`passed`不能授予资格。六项真实配置和运行入口不代表六项能力已经训练完成。

综合课程按六个地形分别晋级：当前档至少32条真实终止记录，最近最多64条通过率达到90%，才开放相邻下一档，最高到第4档。只有真实越过地形边界且没有失败的episode算通过，冷启动与手动reset不计票。这一训练晋级记录与最终独立验收分开。

## 模型和每轮更新

教师输入为同一份5帧本体历史、HIM的下一帧速度3维和归一化特征16维，以及可见地形特征32维。动作头输入96维，输出12个关节动作；critic读取原446维状态及课程时间、稳停进度、已入场3维，共449维；额外3维只用于价值估计。HIM历史剔除30:33的命令，只编码5×42维本体，原5×45帧仍原样供actor取当前帧。

一轮先固定HIM，采样24个控制步并完成全部PPO更新。PPO只更新动作头、可见地形编码器和critic。之后单独用真实下一帧速度和HIM原型交换损失更新HIM。真实终止不进入HIM目标；纯超时保留真实末帧。下一轮采样使用更新后的HIM，这会改变输入表示，但同一轮PPO中的表示保持一致。

教师验收后冻结。学生共享教师的同一个actor和HIM对象，重新随机建立CNN和GRU，只训练视觉模块。动作损失可穿过冻结actor传回视觉输入。GRU缓存最多50张健康新帧，后25帧同时建立新记忆，并逐帧混合新旧输出；满窗后提升已有25帧的新记忆。只有episode重置整体清零。第一段启动以及长时间没有新帧时仍受有限历史限制。采样、序列训练和JIT采用相同边界。每轮24步后做4个epoch、每批最多256条lane的Adam更新；每次Adam前按当前参数重算当前记忆段的burn-in，梯度只跨本轮24步。全无效窗口不伪造GRUCell梯度，Adam不会更新未使用参数的旧动量。

## 观测和终止边界

相机10Hz，控制50Hz。深度从160×90按每格最近有效点缩为64×48，再按4×4格选择近点，保留原像素回投成12×16个xyz与valid，共768维。教师与学生读取同次曝光、同一episode的帧；旧帧不会跨reset使用。有效深度限定0.2–4m，范围外像素记为无效。帧健康单独从过滤前的原始曝光计算：Warp未命中为有限的0，全部像素量程外也可健康；NaN/Inf曝光不健康，教师几何和学生深度一同置零。评价区分`depth_valid`与`depth_has_hit`，相机时钟、episode与帧龄仍严格核对。训练时每次原始采集加入1.5%比例噪声、1%空洞、0.1%近距飞点；原始量程内像素加噪后夹回量程，独立丢点仍保留；同一扰动帧同时生成教师几何和学生深度，保持五个控制步内复用帧一致。仿真安装位置每episode扰动±2mm、RPY各±0.5°，标称光学参数不变。最近点仍会保留量程内的孤立近点，细物体与噪声分布需要实测评估。

仿真关闭自动reset。每次step先保存真实末帧的critic、本体历史和速度，再局部reset。纯超时使用真实末状态价值；真实终止不bootstrap。

桥桩空隙允许射线无命中。支撑来自真实碰撞体的受力顶面接触，核心区触及下层地板计失败。不能以脚下射线缺失直接认定数值故障，也不能把底板当桥面或桩顶。

## 使用

从项目根运行，依赖当前项目的`src`和包目录：

```bash
PYTHONPATH=src:. uv run --no-sync --offline python -m black.run
```

默认只显示计划。有限探针需显式选择执行、控制步数和新输出目录，例如：

```bash
PYTHONPATH=src:. uv run --no-sync --offline python -m black.run --mode probe --execute --course flat_foundation --num-envs 32 --controls 24 --out runs/black_flat_probe
```

教师更新用`--mode teacher --rounds N`。阶段切换用`--bundle`载入当前教师，并提供`--teacher-evaluation`；专项另加`--course specialty --task stairs`。`--resume-learner`恢复同课程、同专项和同配方的优化器、随机状态与累计轮数。已结算课程档位及窗口恢复；物理、相机和GRU episode重新开始，在途记录不晋级，恢复不复现上一进程的物理轨迹。周期存档和最终存档均原子发布到新文件，不覆盖旧包。

模型包绑定当前代码与资产；奖励、模型或碰撞资产变化会拒绝直接加载。文档、测试与安装目录不参与该身份。运行库另行保存：JC教师可以作为纯权重传到不同Torch/CUDA版本的Win，必须在Win重新评估后才能开学生或切阶段；完整优化器续训要求运行库也完全一致。

## 评估范围与学生准入

`black.eval_collect`负责`flat8`、`axes`和`stairs`，`black.course_evaluation`负责`general`和另外五个专项。资格需要同一教师、同一源码、同一范围的191301、191401、191501三个seed完整原始记录。`--max-controls`截短只供诊断，不能准入。原始轨迹必须包含动作前命令、实际动作、终止前状态、相机帧和独立episode；复评不会读取训练success汇总来代替位移与支撑证据。

综合验收覆盖六地形×四难度×两个朝向，每seed48条。非楼梯专项默认覆盖完整几何家族；学生可以先针对已学会的连续前缀训练，使用`--max-level`指定从0开始的最高难度。例如平台`--max-level 2`覆盖5、10、15cm全部三档。楼梯使用`--heights-cm 4 6 8`指定同样连续的前缀。只挑一个容易档位或跳过中间档位不能通过资格。

每个专项档位都覆盖正反方向和0、±15°入场；当前学生范围也限制在这些角度。综合和专项准入均重新检查当前教师的平地基础与纯轴能力。学生从资格结果取得难度上限，训练期间不能自行升级到该范围外；续训配方同时绑定课程、专项和难度上限。平台1.2m、断桥1.8m等最高几何档位是可选完整挑战，不是每次开始专项学生训练的前置条件。通过前缀只能声明该前缀能力。

综合复评由逐步位移、命令方向、脚下有效观测覆盖重新计算通过条件。五个非楼梯专项要求从入口连续通过到出口，四足实际支撑且连续稳停50步；桥桩核心区触底直接失败。楼梯还要求12级顺序接触和平台证据。超时没有稳停不能算专项成功。

## 代码入口和验收边界

- `black/runtime.py`：原生环境、相机与真实末帧。
- `black/model.py`、`black/ppo.py`、`black/run.py`：模型、PPO和HIM更新顺序。
- `black/student.py`、`black/student_training.py`：共享模型和序列蒸馏。
- `support/black/config.py`、`specialty_env.py`、`obstacle_geometry.py`：综合配置、专项过程和真实障碍几何。
- `black/qualification.py`：阶段证据门。原始评分与接触诊断通过也不能替代闭环能力评估。

教师可导出JIT和ONNX；学生JIT包含显式GRU状态和时序输入，学生ONNX尚未开放。正常训练只在控制步边界检查物理有限性；`--debug-first-fault`显式启用逐子步同步取证。首坏子步记录用于定位故障，包含源码身份、教师身份、视觉更新计数和部分物理状态；它没有完整恢复求解器/接触内部状态，不能称为故障重放。4096环境的50帧缓存估算约2.36GiB，连同两份采样缓冲估算约5.33GiB；启动前以当时MemAvailable的80%做内存准入，仿真和实际峰值仍需测量。v3学生JIT调用方须携带`hidden`、`warm_hidden`和`fresh_count`，接收并回传两份状态及更新计数。旧v2导出接口不能直接调用。

本次迁移只进行明确列出的本地与有限仿真验证。正式长训由用户后续决定；旧NaN的真实根因和全课程能力不因迁移自动获得证明。

## 本轮审查补完

平地基础/轴向的PPO初始学习率1e-3，综合3e-4，专项1e-4，均用KL自适应调度。全部六专项都有完成补偿12、49步稳停塑形总额1，以及无有效前进时扣回正向dense奖励；原通关事件总额3仍保留。桥桩无命中不进入抬脚代价，专项只处罚抬脚不足，保留机身触地、低机身和倾角终止；大腿持续触碰0.15秒失败，并有软碰撞代价。延迟队列reset清空。
