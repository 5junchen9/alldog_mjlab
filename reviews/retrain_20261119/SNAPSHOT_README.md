# Black与Wolf新训练架构审查快照

本目录对应JC精简训练仓库，提供全部训练/模型/评估代码、依赖锁、说明和CPU反例。训练顺序为基础平地→纯轴起停→综合六地形→六个专项分支；两种机器人各自共享教师和学生actor。

本公开快照未包含机器人URDF、XML和网格等模型资产。完整可运行源码和资产保存在用户本地Git仓库；Wolf团队资产没有公开分发授权。资产缺项的路径、大小和哈希见ASSET_REQUIREMENTS.json，不能仅用公开目录直接开始物理训练。

审查先读docs/review.md、docs/black.md和docs/wolf.md。验证结果以VALIDATION.json为准。短程CPU/GPU工程检查没有产生合格策略；旧NaN根因、4096环境长期稳定性、完整任务能力及实机链仍需新训练证据。新模型的PT只能按新合同加载，完整优化器恢复要求代码、资产与运行库一致。

本PR保持草稿；没有合并main，也没有启动正式长训。旧v1/v2审查目录从当前树移除，历史提交仍保留。机器清理明细和个人目录记录仅在本地审计交付中提供。
