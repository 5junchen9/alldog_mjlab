# Black共享actor v2

本目录实现“全部从零、先平地、再低速纯轴、再楼梯”的教师训练，以及合格教师的视觉学生蒸馏。当前入口默认只打印计划，正式长训没有启动，尚无通过本版完整资格的教师。最终测试、静态检查和有限GPU回执统一见[BlackV2审计索引](/home/wujuncheng/Documents/Codex/2026-11-19/wo-x/outputs/BlackV2审计索引.txt)，代码与证据交付包为`BlackV2代码与证据.zip`。短程更新只证明相应链路可运行。

## 从零与共享的具体含义

默认不读取r800、8954或任何旧checkpoint。HIM、actor、几何编码器、critic、CNN和GRU均随机初始化，记录种子和模块来源。复用旧项目的网络类和原生环境源码，不复用旧权重。critic使用独立种子，避免环境初始化消耗随机数后改变初始critic。

教师输入为当前本体状态p45＋HIM19＋可见地形32，共96维；actor为96→512→256→128→12。HIM读取5帧本体历史，19维输出保持“下一步机身速度预测3维＋归一化隐变量16维”含义。教师几何编码器为768→128→32，critic独立读取完整446维特权状态并保留原分组归一化。

学生直接使用教师的同一个actor和HIM对象，没有第二套学生动作头。首次进入学生阶段时，CNN和GRU重新随机初始化；学生学习相机特征，合格教师的actor/HIM始终冻结。

## 损失与梯度

|阶段|实际更新|固定部分|
|---|---|---|
|教师24步采样和整轮PPO|actor、几何编码器、动作分布；价值损失更新critic|HIM固定；每个PPO小批次从保存的原始geometry重新编码，保留梯度|
|PPO结束后的HIM辅助更新|HIM编码器、目标编码器、原型|actor、几何编码器和critic不参与此更新|
|学生动作均值与地形特征蒸馏|CNN＋GRU|教师目标无梯度；actor/HIM权重固定，动作损失仍穿过actor回传到视觉输入|

HIM辅助目标为下一步速度Huber损失和原有原型交换损失。标签来自reset前真实下一帧及速度，排除真实终止样本，纯timeout可以使用。每轮辅助更新后重新冻结HIM，下一轮才使用新表示。HIM更新会在轮间改变策略输入，其影响需要实测；它不受上一轮PPO裁剪直接约束。

学生每轮自己控制24步，在相同访问状态上查询教师；按128个环境分块回传，合计执行一次Adam更新。整窗没有fresh valid帧时，未调用的GRUCell保留`grad=None`，其权重、Adam动量和步数不变。实际参与计算的梯度必须存在且有限。

## 相机与连续记忆

原始深度是160×90的光轴Z距离，单位米。先在每个缩小区域内选最近有效点得到64×48，并保留该点的原始pixel索引；学生CNN读取这份深度。教师再对每个4×4区域选最近有效点，按原始pixel和实际内参回投，得到12×16个`xyz/4＋valid`，共768维。除以4是尺度归一化，不是截断4m以外的深度。

教师和学生使用同一相机帧、可见范围、遮挡结果和时钟，控制50Hz、相机10Hz。完整地形和raw446只进入critic。近点采样减少旧固定采样点之间的漏检，也可能更容易选中近距离噪点；薄物体与噪声表现仍需独立验收。

学生在CPU保留当前episode从出生起的全部fresh valid帧和原始时间标识。每次视觉参数更新后，用新CNN/GRU从零重算整段前缀hidden，再继续控制；梯度只回传当前24步。reset清除对应lane的前缀。前缀受原生episode上限约束，启动前检查内存估算；4096环境的长episode仍需单独验证内存、耗时和稳定性。

## 课程与资格

|入口阶段|训练分布|进入条件|
|---|---|---|
|`flat_foundation`|全平地；静止、基础轴向运动、停车|默认从零起步|
|`flat_axes`|全平地；0.10/0.25纯轴起动、反转、停车|当前教师通过三个固定seed的完整flat8|
|`stairs`|25%平地纯轴＋75%楼梯，4–30cm、路线双向及入场角变化|同一教师通过三个seed的flat8和axes|
|`student`|显式选择课程，由学生自身动作采样|同一冻结教师另通过三个seed的完整54格楼梯|

资格逐次读取原始MANIFEST、RESULT和trial重新评分，要求同一bundle、当前教师与源码身份，全部固定试验通过，无无效深度帧。手填`passed`、旧SCORE、短程探针和课程内部成功率都不能授权晋级。楼梯课程只有严格过梯稳停计成功，timeout未停车不会投成功票。详情见[EVALUATION_PROTOCOL.md](./EVALUATION_PROTOCOL.md)。

## 运行与恢复

在项目根目录查看默认计划，不创建环境或更新参数：

```sh
uv run --no-sync --offline python preparation/rough_v2/shared_actor_v2_20261119/run.py
```

执行需显式`--execute --out 新目录`。`probe`最多120控制步；`teacher`和`student`还要求明确`--rounds`。本轮仅做有限验证，不能据此启动正式长训。

- 不带来源参数：全部随机，默认`flat_foundation`。
- `--bundle`：加载本版模型权重，建立新学习器。跨课程还必须提供该教师的`--teacher-evaluation`；首次学生训练会重新初始化CNN/GRU。
- `--resume-learner`：恢复同课程、同配方、同环境数和参数绑定顺序的v2学习器；与`--bundle`互斥。学生恢复仍核验冻结教师资格。
- `--rounds`表示新增轮数；`--save-every`默认每100个累计完整轮保存编号包，结束另存`teacher.pt`或`student.pt`。原子发布且拒绝覆盖已有文件。

教师学习器包包含actor、几何编码器、HIM及其辅助参数、critic与归一化、动作分布、PPO/HIM两个优化器、学习率、随机状态及累计计数。学生包保存CNN/GRU和优化器，绑定同一冻结教师。包可独立恢复其权重，无需原r800文件；v1包不能冒充v2恢复。物理、课程、相机、episode、GRU和前缀全部冷启动，因此恢复学习器不会复现原物理轨迹。

原生环境先保存reset前的`terminal_critic`、真实下一帧history和机身速度，再局部reset。纯timeout使用真实`V(s_next)`补值，真实终止不补值；移除上游旧timeout补偿，避免重复计算。

## 导出与故障边界

教师TorchScript和ONNX都使用`history[B,5,45]＋geometry[B,768]`，输出12维动作均值。学生已实现TorchScript，输入显式包含history、米制depth64、hidden、fresh/reset/valid和帧龄，输出动作与新hidden；学生ONNX尚未实现或验证。动作顺序、0.25比例、原生0–2步延迟与PD目标由导出manifest明确，调用方必须维护时间标识及外部动作历史。导出等价检查不等于实机部署验收。

首次坏状态记录绑定教师身份与策略更新计数、源码、软件版本、时钟、随机状态、延迟动作与关键物理状态，保留最早异常；学生故障记录不逐次复制整套CNN/GRU权重。接触求解器内部状态等尚未完整恢复，记录不能称为可精确重放的故障存档；旧训练NaN原因仍未闭合。未部署Win，未验证真实机器人。

## 文件入口与历史

`run.py`组织训练及分离HIM更新，`model.py/ppo.py`定义教师与PPO，`student.py/student_training.py`负责视觉蒸馏与前缀记忆，`terrain.py/runtime.py`负责感知和原生时序，`checkpoint.py/learner_state.py`负责身份与恢复，`curriculum.py/qualification.py`负责课程与资格，`eval_*`负责独立采集和评分，`export.py/fault_capture.py`负责导出与故障证据。

本目录依赖项目的`src`、资产、原生环境和历史网络类源码，单独复制本目录不能直接运行。目录内`.txt`仅作指向本说明的入口；v1历史实现与原始证据保留在`../shared_actor_v1_20261119`，旧权重和旧训练入口未改。
