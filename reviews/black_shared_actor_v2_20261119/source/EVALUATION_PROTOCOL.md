# Black共享actor v2评估与阶段资格

本规范对应`shared_actor_evaluation_v2`、协议`shared_actor_absolute_qualification_v2`和资格索引`all_cells_all_seeds_v2`。规则已实现，当前尚无完整合格教师。正式长训未启动。最终验证范围及源码身份见[BlackV2审计索引](/home/wujuncheng/Documents/Codex/2026-11-19/wo-x/outputs/BlackV2审计索引.txt)。

## 固定试验与准入

独立评估使用三个保留seed：191301、191401、191501；同一面板第二批使用seed＋1。训练禁止使用这六个seed。每批32个环境，最后一批补齐的lane不计分。每条试验只评价第一次episode；跌倒后的新episode不能替换原失败。

|待进入阶段|必须完整通过的面板|原始attempt数|
|---|---|---|
|`flat_axes`|flat8×三个seed|3|
|`stairs`|flat8、axes各三个seed|6|
|`student`|flat8、axes、完整stairs各三个seed|9|

每条登记试验都必须成功，要求成功数＝分配数、独立episode数＝分配数，且无无效深度帧。所有attempt绑定同一bundle文件、当前teacher_id和当前源码清单hash。资格入口重新核验原始文件并计算结果，不信任已保存的SCORE或`passed`摘要。缺格、重复、换教师、源码改变、行政截短、FAILED与RESULT并存均不能通过。

`flat_foundation`从零起步无需资格。跨教师课程只能通过`--bundle`加载当前教师，再提供对应资格索引；同课程的严格学习器恢复不重复过阶段门。学生初训和恢复都核验完整教师资格。资格通过不会自动启动训练。

## flat8：基础动作

每个seed共32条：8项各4条，每条400控制步。控制频率50Hz。

- 前进、后退、左横移、右横移：目标线速度绝对值0.30m/s。
- 左转、右转：目标角速度绝对值0.50rad/s。
- 反转：前150步前进，之后后退。
- 停车：前150步前进，之后零命令。

运动段最后100步的带方向平均目标轴速度须达到目标的50%。反转和停车还要求第75–149步平均前进速度至少0.15m/s。停车最后100步平均平面速度不超过0.10m/s，平均绝对偏航角速度不超过0.15rad/s；第150步之后还须连续50步满足下节相同的稳停速度、倾角和至少两脚接触条件。真实物理失败优先判失败。

## axes：低速纯轴起动、反转、停车

每个seed共24条：vx/vy/wz三轴×0.10/0.25两幅值×正负方向×朝向0/π。线速度单位m/s，角速度单位rad/s。每条900步：0–99步静止，100–349步按目标运动，350–599步反向，600–899步停车。

每个运动段跳过前50步，余下200步的带方向平均目标轴速度须达到目标的50%。响应时间记录首次连续10步达到半目标的时刻，未达到时记空值，不用最后一帧代替整段表现。

停车第650–899步平均平面速度须不超过0.10m/s，平均绝对偏航角速度不超过0.15rad/s；第600步之后还须有连续50步同时满足平面速度≤0.08m/s、绝对偏航角速度≤0.12rad/s、倾角≤0.35rad、至少两脚接触。50步对应1s稳停。

## stairs：真实过梯并稳停

每个seed固定54格：高度4、6、8、10、12、15、20、25、30cm×路线双向×入场角−15°/0°/15°。路线双向指世界路线两端出发，原生命令保持机身向前通行，不代表已验证倒走楼梯。每条最多6000控制步，即120s。

通过必须同时具备以下原生证据：

1. 12个踏面按顺序验证，第6级后经过landing。
2. 到达原生判定的安全出口，出生、首次验证通过和闭合时钟有序且属于同一episode。
3. 末尾连续50步均保持完整过梯证据、安全出口、四脚接触，且线速度范数≤0.08m/s、角速度范数≤0.12rad/s、倾角≤0.35rad。评分器复核逐帧状态，不仅读取累计稳停计数。
4. 真实`terminated=True`并发生对应episode递增；仅手填`strict_finish`标志不能通过。

物理失败优先于strict_finish，strict_finish优先于timeout。只跨过终点、超时未停车、终止后补帧、后续episode完成，都不能补成成功。训练课程内的`pass_timeout_no_stop`已转为失败票，课程升级统计依然只属于训练调度，不代替这套独立资格。

## 采集与评分证据

采集前写MANIFEST，固定完整roster、实际batch/lane/seed、协议、动作方式、教师、bundle和源码hash。模型冻结，使用动作均值，优化器调用为0。每步保留命令、速度、倾角、四脚接触、帧与时间标识、请求动作、实际延迟动作和PD目标；楼梯另保留顺序踏面、landing、safe_exit、strict稳停和reset前闭合证据。

相机10Hz、控制50Hz，教师使用与学生相同的近点缩小深度及真实源pixel回投。所有末帧证据在局部reset前捕获，不能把新出生状态当作上个episode的终点。

环境关闭、教师和源码未变后才发布RESULT。物理失败也可以产生完整采集结果，`collection_complete=True`只表示证据收齐。`--max-controls`截短、挑选高度/角度或单个自选seed只做诊断，不能拼成资格。RESULT与SCORE分别表示采集和独立评分；评分异常时进程非零退出，不生成SCORE，已有RESULT不因此获得通过结论。

源码清单使用项目根相对路径，覆盖本目录Python、直接依赖的历史源码和`src`源码。它不等于全部软件包与资产的完整环境快照；换软件或资产后的迁移表现需要重新核查。

## 使用顺序

以下命令在项目根执行，仅打印计划：

```sh
uv run --no-sync --offline python preparation/rough_v2/shared_actor_v2_20261119/eval_collect.py --suite flat8 --panel
```

实际采集还需明确`--bundle`、`--execute`和新的`--out`。`--panel`生成三个固定seed的完整子目录；单独默认seed仅用于诊断。flat8、axes和stairs分别采集，不能更新模型后继续拼接同一个资格面板。

`eval_score.py --manifest MANIFEST.json --result RESULT.json --out SCORE.json`复核单次采集。`qualification.py --stage 阶段 --attempts 原始目录列表 --teacher-id 身份 --source-sha256 源码hash --out 资格索引.json`建立索引并立即重算。即使失败索引文件已写出，训练入口仍会重新评分并拒绝放行。

这套资格只覆盖固定仿真任务。它不证明4096环境长训稳定、噪声鲁棒性、真实机器人表现，也不证明旧NaN根因已解决。首次坏状态capture用于定位，尚不能精确重放接触求解器全过程。v1旧协议和记录保留在`../shared_actor_v1_20261119`，不作为v2资格证据。
